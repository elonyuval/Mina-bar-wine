# מינה — בר יין מקומי, נתניה

אתר תדמית של **Mina Local Wine Bar**, קרל פופר 7 נתניה.
עמוד אחד, עברית (RTL), HTML/CSS/JS סטטי — בלי build ובלי תלויות.

## הרצה מקומית

```bash
python3 -m http.server 8000
# פתחו http://localhost:8000
```

## מבנה

```
index.html              כל תוכן העמוד + JSON-LD לגוגל
assets/css/style.css    עיצוב
assets/js/menu-data.js  ← התפריט. זה הקובץ היחיד לעדכון מחירים/פריטים
assets/js/main.js       ניווט, רינדור התפריט, אנימציות
assets/img/             תמונות (טרם הוזנו)
```

## איך מעדכנים את התפריט

עורכים רק את `assets/js/menu-data.js`. המבנה:

```js
{
  title: 'יין כוסות — אדום',
  items: [
    { name: 'שם היין והיקב', note: 'אזור, כשרות', price: 54 },
  ],
}
```

קטגוריה שכל הקבוצות בה ריקות לא תוצג באתר כלל — אפשר להשאיר אותה כשלד עד שיהיה תוכן.

## תמונות ולוגו

כל הנכסים ב-`assets/img/`, נגזרו מקבצי המקור של הבר:

| קובץ | שימוש |
|---|---|
| `logo-burgundy.png` | הלוגו בכותרת (על רקע בהיר) |
| `logo-white.png` | הלוגו בפוטר (על רקע כהה) |
| `hero.jpg` | רקע ראש העמוד |
| `about.jpg` | סקשן "על מינה" |
| `gallery-1..4.jpg` | הגלריה |
| `og.jpg` | תצוגה מקדימה בשיתוף ברשתות |
| `favicon.png` | אייקון הלשונית |

שני קובצי הלוגו הם שקופים, ונגזרו מקובץ הלוגו המקורי (לבן על בורדו) על ידי
חילוץ ערוץ אלפא מהבהירות וצביעה מחדש. צבע המותג `--bordeaux: #8b4140`
ב-`style.css` נדגם מרקע אותו קובץ.
